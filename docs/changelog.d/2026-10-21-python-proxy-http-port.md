**Fixed**: plain HTTP through the proxy no longer reaches any port on an allowed host. A `GET http://api.anthropic.com:22/`, or a `GET /` with that `Host` header, made the proxy connect to port 22, since `ConnectPort 443` only binds CONNECT. The proxy now checks the whole URL: CONNECT on 443 and plain HTTP on 80, nothing else. A refusal in `RunResult.proxy` now reads `filtered url "host:443"` instead of `filtered domain "host"`.
