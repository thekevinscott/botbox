**Changed**: a `ClaudeAgent` with an `api_key` no longer writes the key into the box. `.claude/api_key` holds a placeholder, Claude Code is pointed at the credential proxy with `ANTHROPIC_BASE_URL`, and the proxy sends the real key to `api.anthropic.com` as `x-api-key`, dropping the `Authorization` header Claude Code also sends. Only `POST /v1/messages` and `/v1/messages/count_tokens` go through. `ClaudeAgent.allow` is `()` with an API key as well, and `credential_source` is no longer `None`.
