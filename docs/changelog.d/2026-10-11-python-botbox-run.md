**Added**: `box.run(command, *, mounts=(), workdir=None)` and `RunResult(stdout, stderr, exit_code, transcript, proxy)`, exported from `botbox`. `run()` builds the image, runs `command` as `sh -c` on a per-run `--internal` network behind a deny-by-default proxy, with a fresh temporary home holding the staged credentials, and returns the output, the transcript files and the proxy log. `exit_code` is -1 when the Docker daemon dies mid-run.
