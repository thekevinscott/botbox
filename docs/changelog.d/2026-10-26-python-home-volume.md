**Changed**: a run's home is a Docker volume, `botbox-home-<token>`, labelled `botbox.run=<token>` and removed when the run ends, in place of a `botbox-<token>-*` directory in the host temp dir. The credentials are staged in a host temp directory that is deleted before the agent starts, then unpacked into the volume by a short-lived `botbox-stage-<token>` container. A run whose owner is killed outright leaves the volume, staged credentials included; remove it with `docker volume rm`.
