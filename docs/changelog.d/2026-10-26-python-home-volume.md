**Changed**: the agent's home is a Docker volume, `botbox-home-<token>`, labelled `botbox.run=<token>`, instead of a host temp directory. The credentials are staged in a host temp directory and copied in through a staging container that never starts, both removed before the agent starts. The home is owned by your uid with mode 700. A run killed outright now leaves this volume behind as well as `botbox-run-<token>`; remove both by label. The run's temp directory still holds the streams and proxy log.
