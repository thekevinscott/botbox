**Added**: `Botbox(timeout=...)` bounds every `run()` and `session()` in seconds, and `run(timeout=...)` and `session(timeout=...)` set one for a call. The default is `None`, no limit. The clock starts once the image is built; for a session it covers the whole block. When it runs out, the run or session tears down as a cancel does and raises `botbox.Timeout`, a `TimeoutError` whose `result` holds the output, transcript and proxy log captured so far, with `exit_code` -1. A timeout that isn't positive raises `ValueError`.
