**Fixed**: SIGTERM to a process holding an open box, or inside `run()` or `session()`, now tears down the agent and proxy containers, networks and temp directory, mid-run or mid-setup. While a box is held, SIGTERM raises `SystemExit`, so the process exits 143 rather than dying by signal (-15). A SIGTERM handler the program installed itself is left alone. Agent containers are now named `botbox-agent-<id>`.
