**Added**: `await AsyncBotbox.run(command, *, mounts=(), workdir=None)`, the async run. It returns the same `RunResult` as `Botbox.run()` under the same lockdown. Cancelling it, or an `asyncio.timeout` firing, removes the run's containers and temp home, even through a second cancel. Its containers carry the label `botbox.run=<token>` and are removed by the run, not by `--rm`. It raises `DockerException` when the Docker client dies while the daemon is up, and when the image is missing, where `Botbox.run()` returns exit 125. It warns instead of raising when teardown fails after the command ran. Don't fork while a run is in progress.
