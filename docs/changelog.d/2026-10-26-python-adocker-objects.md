Changed: **BREAKING** `adocker` exports classes instead of functions: `Container`, `DockerException`, `Dockerfile`, `Image` and `Volume`. `Image.run` takes `docker run`'s flags as keywords and hands output to `stdout`/`stderr` sinks. `Volume` takes a `labels` mapping. botbox writes a run's streams and proxy log to its temp directory first and copies them to `output`; a failing `output` file is warned about and dropped. `version()` is gone. A daemon that goes away mid-run raises `DockerException` instead of returning `exit_code` -1. A Docker error's `stderr` holds the last 64 KiB of the agent's stderr, not a path. Without `output`, a session no longer keeps its streams in memory: `Session.stdout` and `Session.stderr` are gone. See [the migration](../migrations.d/2026-10-26-python-adocker-objects.md).
