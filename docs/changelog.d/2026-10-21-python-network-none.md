**Changed** (**BREAKING**, see [the migration](../migrations.d/2026-10-21-python-network-none.md)): agent containers run with `--network none` and reach the proxy over a unix socket, through a relay the harness images ship. No run creates a Docker network. The agent joins the proxy's PID namespace, and the proxy lives only while the owning process holds its stdin, so a SIGKILLed owner no longer leaves a running agent or proxy behind. tinyproxy listens on loopback only, in place of the per-run subnet allow. The proxy runs as pinned uid 100, and an agent running as that uid is refused with exit code 125.
