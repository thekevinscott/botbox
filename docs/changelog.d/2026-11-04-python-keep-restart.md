Added `Botbox.run(keep=name)` to retain the agent container and its socket volume after exit, cancellation or timeout. The kept agent carries `botbox.keep=<name>` so `Botbox.restart` can distinguish it from sidecars. `RunResult.container_name` reports the retained name. `Botbox.restart(name, command, ...)` continues from the kept filesystem under a fresh lockdown, appending to the log files in `output`.
