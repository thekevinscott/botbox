**Changed** (**BREAKING**, see [migration](../migrations.d/2026-10-27-python-pi-1-4.md)): the pi image runs pi 1.4.0, up from 0.74.0. pi's `message_update` and `tool_execution_update` events reach callers again, in session events and `RunResult.stdout`; `message_update` now carries only the delta, so a turn's output grows linearly. A pi session turn ends at `agent_settled` instead of `agent_end`, since pi can retry or compact after `agent_end`. With no `model`, `PiAgent` no longer passes `--provider`, which pi 1.0 rejects without `--model`. The image sets `PI_OFFLINE=1`, so pi makes no requests to `pi.dev`.

**Fixed**: flags a subclass appends to `PiAgent.session_command()` or `command()` reach pi again.
