**Added**: `await botbox.reap()` removes what runs whose owner died left behind: their containers, in any state, and their temp home with its staged credentials. It returns their tokens. Every `run()` and `session()` calls it first. A run holds an exclusive `flock` for its whole life, and a run whose lock is free counts as dead, so an owner killed outright (SIGKILL, OOM) is cleaned up on the next run. A run it can't clear is a `RuntimeWarning`, retried on the next sweep.

**Changed**: a run's temp home moves from `botbox-<token>-*` in the system temp directory to `botbox-<uid>/<token>/`, owner-only, beside its lock file `<token>.lock`. botbox refuses to run if `botbox-<uid>` exists and isn't a directory only the current user can open. Temp homes left by runs before this release aren't swept.
