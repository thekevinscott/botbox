**Added**: `async with AsyncBotbox.session(*, mounts=(), workdir=None) as live`, the async session, and `AsyncSession`. `live.stream(text)` yields each event as it arrives and ends at the agent's turn end; `await live.message(text)` collects a turn. Leaving the block ends the CLI's input, waits for it, tears down as `AsyncBotbox.run()` does, and leaves the `RunResult` in `live.result`. Cancelling, mid-turn or not, kills the CLI and removes the session's containers and temp home, even through a second cancel. It raises `DockerException` when the block ends if the Docker client died while the daemon was up or the container never started.
