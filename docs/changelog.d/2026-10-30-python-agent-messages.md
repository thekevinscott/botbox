Changed: `session()` yields the agent instead of a `Session`. `agent.send(text)` sends a message without waiting. `agent.replies` and `agent.messages` each return a new iterator of `Message`s from that moment until the CLI exits: the agent's messages that have text, or every message. `agent.on("reply" | "message", fn)` calls `fn` with each. A `Message` has the harness's `type`, its `text` and the raw `event`; each agent names its types in `MESSAGE_TYPE`. `agent.result` holds the `RunResult` after the block. Removed: `Session`, its `stream()` and `message()`, and `Agent.parse_event`; agents read messages with `read_message(line)`.
