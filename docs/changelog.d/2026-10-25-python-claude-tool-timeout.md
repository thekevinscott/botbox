**Added**: `ClaudeAgent(tool_timeout=...)` caps every Bash call at that many seconds. It sets `BASH_DEFAULT_TIMEOUT_MS`, `BASH_MAX_TIMEOUT_MS` and `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1` on the CLI's command, also exposed as `ClaudeAgent.env`, so that a timed-out command is killed, not moved to the background. That also turns off `run_in_background`. The default, 0, is no limit. A negative value raises `ValueError`.
