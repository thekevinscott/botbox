**Added**: `Agent.read_message(line)` returns the `Message` one line of the CLI's stdout holds, or None. `ClaudeAgent` reads stream-json `assistant` and `user` lines; `PiAgent` reads rpc mode's `message_end` events. A `Message` has the harness's `type`, its `text` (the text parts joined, empty when there are none) and the raw `event`. `botbox.Message` is exported. Nothing in a session calls it yet.
