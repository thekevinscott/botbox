**Changed**: the proxy's socket lives in a Docker volume per run, `botbox-run-<token>`, labelled `botbox.run=<token>` and removed when the run ends, in place of a `sockets/` directory in the host temp dir. The allowlist reaches the proxy as an environment variable in place of a `filter` file there. The proxy log starts with a `botbox-proxy: listening` line, which botbox waits for before starting the agent. A run whose owner is killed outright leaves the volume; remove it with `docker volume rm`.
