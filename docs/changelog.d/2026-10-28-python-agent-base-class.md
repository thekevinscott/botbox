Changed: `Agent` is now an abstract base class that every agent subclasses, and `ClaudeAgent`, `CodexAgent` and `PiAgent` do. Subclasses implement `stage_auth` and `command`. `session_command`, `encode` and `turn_ended` default to raising `NotImplementedError`, and `credential_source` defaults to `None`. `SessionAgent` and `InjectingAgent` are removed. `session()` on an agent without a session mode now raises `NotImplementedError` where a duck-typed one raised `TypeError`.
