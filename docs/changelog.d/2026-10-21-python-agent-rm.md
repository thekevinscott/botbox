**Removed** (**BREAKING**, see [the migration](../migrations.d/2026-10-21-python-agent-rm.md)): `RunResult.container`. Agent containers, for runs and sessions, now run with `--rm`, so a finished run, a raising run and an owner killed with SIGKILL leave no container behind. The output, exit code, transcript and proxy log are all read before the container goes. `with Botbox(...)` no longer removes containers on exit; it still makes SIGTERM unwind.
