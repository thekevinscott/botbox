**Changed** (**BREAKING**, see [the migration](../migrations.d/2026-10-26-python-pi-openrouter-injection.md)): a `PiAgent` on `openrouter` no longer copies its key into the box, with `api_key` or the host's `auth.json`. The box gets a placeholder key and a `models.json` that points pi at the credential proxy, which sends the real key to `POST /api/v1/chat/completions` on `openrouter.ai`. `PiAgent.allow` is `()` on `openrouter`, and `PiAgent.credential_source` is set. A host key that is a `!command` or an env var name raises `ValueError`. Custom providers keep copying `auth.json` and `models.json`.
