**Changed** (**BREAKING**, see [the migration](../migrations.d/2026-10-22-python-run-files.md)): `RunResult.transcript` and `RunResult.proxy` are paths, not contents. Each result owns a temp directory, `RunResult.files`, deleted when the result is garbage collected, on `cleanup()`, or at the end of a `with result:` block; `save(dest)` copies it somewhere permanent. The transcript is moved out of the agent's home without being read or following a link, and the proxy log is copied, so neither is held in memory. `image` now comes before `files` in the constructor's positional order.
