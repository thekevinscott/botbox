**Changed** (**BREAKING**, see [the migration](../migrations.d/2026-10-26-python-claude-login-injection.md)): a `ClaudeAgent` on the host's Claude Code login no longer copies the login into the box. Its home gets a placeholder `.credentials.json`, Claude Code is pointed at the credential proxy with `ANTHROPIC_BASE_URL`, and the proxy sends the real token to `api.anthropic.com`. botbox follows the host's file while the agent runs and sends a refreshed token from the next request. `ClaudeAgent.allow` is now set per instance: `()` on a login, `("api.anthropic.com",)` on an API key.

**Added**: `CredentialsExpired`, raised by `run()` and `session()` before anything starts when the host login has already expired. `InjectingAgent`, an agent protocol with a `credential_source`, plus `CredentialSource`, `Credential` and `Injection`, exported from `botbox`. Custom agents without `credential_source` keep copying their credentials as before.
