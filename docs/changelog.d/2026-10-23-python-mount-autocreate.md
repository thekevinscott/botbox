**Changed**: A mount whose host path doesn't exist no longer raises `FileNotFoundError`. `run()` and `session()` create it as a dir, parents included, owned by the calling user, before the container starts. A typo'd path now mounts a new empty dir, a missing `"ro"` source shows up as an empty dir, and a missing single-file mount is created as a dir. A `workdir` outside every mount still raises, and then nothing is created.
