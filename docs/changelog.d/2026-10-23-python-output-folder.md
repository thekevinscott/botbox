**Changed** (**BREAKING**, see [migration](../migrations.d/2026-10-23-python-output-folder.md)): `run()` and `session()` require an `output` folder. stdout, stderr, transcripts and proxy logs are written there live and remain after teardown, including cancellation and timeout. `RunResult` contains only `exit_code`. Sessions parse events from a tail subprocess; non-event lines remain on disk. Custom agents name their `sessions_dir` instead of a transcript glob.
