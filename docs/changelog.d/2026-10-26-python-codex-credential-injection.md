**Changed** (**BREAKING**, see [the migration](../migrations.d/2026-10-26-python-codex-credential-injection.md)): `CodexAgent` no longer puts a real credential in the box, on the host's ChatGPT login or with `api_key`. Its home gets a placeholder `auth.json` and a `config.toml` whose model provider points Codex at the credential proxy, and the proxy sends the host's access token to `chatgpt.com` (`/backend-api/codex/responses` and `/models`) or the key to `api.openai.com` (`/v1/responses`). `CodexAgent.allow` is `()` in both modes, `CodexAgent.command()` adds `--disable apps`, and `CodexAgent.credential_source` is the login or key the proxy sends. A login that has already expired raises `CredentialsExpired` before the run starts.
